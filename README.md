# RHnejad.github.io

Personal website of Reyhaneh Hosseininejad, a PhD researcher in robotics at EPFL's VITA Lab working on computer vision and machine learning for 3D human motion.

Live at: https://rhnejad.github.io

## Structure

- `index.html`: home (about, publications, contact)
- `projects.html`: projects across PhD, master's, undergraduate, and side work
- `cv.html`: full CV
- `beyond.html`: personal interests and non-work
- `styles.css`: all styling
- `assets/`: images, CV PDF, fonts, favicon

Static site, no build step. GitHub Pages serves from the root of `main`.
